# 김윤덕

<!-- profile:headline:start -->
**제품의 문제를 정의하고, 도메인 설계부터 구현·운영까지 연결하는 엔지니어입니다.**

Product Engineer · Node.js / TypeScript · CTO / PO 경험
<!-- profile:headline:end -->

<!-- profile:intro:start -->
고객의 업무를 이해하는 일에서 개발을 시작합니다. 무엇을 만들지 결정하는 제품 전략과, 그것을 실제로 동작하게 만드는 기술 설계가 한 흐름으로 이어져야 한다고 생각합니다.

스타트업에서 B2B SaaS와 디지털 전환 솔루션을 처음부터 만들며 백엔드·화면·인프라를 함께 책임졌습니다. NestJS와 TypeScript로 도메인 경계를 설계하고, Vue/Nuxt와 Next.js로 사용자에게 닿는 기능을 구현했습니다. CTO와 PO로 일하며 기술 표준과 개발 프로세스를 세우고, 현장 관찰과 인터뷰를 바탕으로 제품의 방향을 조정해 왔습니다.

좋은 코드는 사람이 읽기 쉽고 의도가 분명한 코드라고 믿습니다. 이름과 책임을 명확하게 나누고, 성능은 측정한 뒤 개선하며, 다음 사람이 판단의 근거를 따라갈 수 있도록 기록합니다.
<!-- profile:intro:end -->
